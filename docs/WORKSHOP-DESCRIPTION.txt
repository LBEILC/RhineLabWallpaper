【Rhine Lab · 莱茵生命交互桌面】
以莱茵生命档案终端为灵感，将日常工具与玻璃档案阵列融入桌面的非官方同人交互壁纸。

【桌面工作台】
查看时间与日期，记录最多三条今日事项，追踪重要日程，使用专注计时，显示当前歌曲、封面与播放进度。各项功能和界面元素可按需开启或隐藏。

【档案展示】
拖动浏览循环档案阵列，点击读取档案内容，进入 360° 查看器旋转、缩放和拆解模型。

【自定义画面】
亮色与暗色配色（可按时间自动切换）、三种音乐律动、静止呼吸、HUD 曲面与鼠标追踪，以及可调的颗粒、色散和暗角。支持界面边距、高／中／低模型精度、自定义画质与超级性能模式，也可关闭 3D，搭配自己的图片背景使用工作台。

【使用说明】
在 Wallpaper Engine 壁纸属性顶部选择「语言 / Language → 简体中文 / English」。原有英文开场与图形文字保持原样，全部配置统一在 WE 属性调整，壁纸内不再提供设置弹窗。可在属性中切换模式、填写登录人姓名、事项与日程，调整显示内容和画面效果，并可设置自动切换明暗的时间。媒体信息取决于系统与播放器支持；音乐律动需要启用音频响应。波纹接力小游戏可手动进入。
如果创意工坊条目暂时无法订阅（Steam 反垃圾内容检查期间会显示“不兼容”），可以从 GitHub Releases 下载构建包，解压到 Wallpaper Engine 的 projects\myprojects 目录后本地加载，功能与工坊版一致。

Rhine Lab · Interactive Desktop

An unofficial Arknights fan wallpaper inspired by the Rhine Lab archive terminal. A glass archive array shares your desktop with a clock, up to three daily tasks, an event countdown, a focus timer and system media information. Browse 40 archives, save records, export text, or inspect and explode the model in the 360° viewer.

English is available: choose Language / 语言 → English at the top of this wallpaper's properties in Wallpaper Engine. All persistent settings now live in that panel. Existing English opening graphics remain unchanged. Language changes preserve your active archive, saved records and focus timer; your names, tasks and media titles stay as supplied. Property labels and dropdown options follow Wallpaper Engine's own interface language; group headings display both Chinese and English.

Customize light/dark themes and scheduled switching, three audio response styles, idle breathing, curved HUD and mouse tracking, grain, chromatic aberration and vignette. Adjust model detail, graphics quality and margins, or turn off 3D and use your own background image. Replay the opening from the bottom-right button.

System media features depend on your player. Audio response requires Wallpaper Engine audio recording. Ripple relay starts manually. All wallpaper resources run locally. Font notices and licenses are included in the package.
