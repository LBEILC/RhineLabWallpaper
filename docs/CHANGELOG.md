# 更新日志

按开发日期倒序记录已保留的功能更新；日期不代表创意工坊的实际上传时间。

2026.09.11
• 新增「登录身份」：在 WE 属性中填写登录人姓名，开场身份确认、页脚与访问记录同步显示；开场 ID CONFIRMED 前缀保持原字形，只有姓名部分使用 MiSans，留空恢复 JOYCE MOORE。
• 新增按时间自动切换明暗：分别设置切换为暗色与亮色的时间，支持跨午夜；手动切换会在下一个时间点被自动结果覆盖。
• 新增 GitHub Releases 构建包：推送 main 后自动构建，下载压缩包解压到 projects\myprojects 即可本地加载；创意工坊条目被 Steam 反垃圾检查标记时仍可使用。
• 优化工作台时间显示：大时钟、专注倒计时、播放器时间及页脚时钟启用 MiSans 居中冒号，保留数字滚动动画。
• 统一工作台英文眉题与页脚标识的 Novecento 字形，保留中文内容与数字滚动排版。
• 更新开场验证、处理与欢迎文字的 Novecento 字形，并校准左上 RHINE LAB 标题字重，保留逐字动画与声音节奏。
• 修正开场 Logo 下方 RHINE·LAB 小字的重复重绘问题，改善开启 HUD 时的文字稳定性。
• HUD 曲面与鼠标追踪扩展到开场：Logo、验证文字、圆环与欢迎画面沿用同一效果，并与工作台连续衔接。
• 修复部分数字（如 8、9）和切歌文字的滚动动画中断；长歌名、歌手名自动省略，悬停可查看完整内容。
• 页脚时钟改为时、分、秒独立滚动，支持连续进位。
• 工作台时钟、专注倒计时、播放器时间及切歌文字加入滚动过渡；减少动态效果时直接显示。
• 改善自定义图片背景下底部按钮、导航、待办和提示文字的对比度，保留原有玻璃背景。

2026.09.10
• 自定义图片新增上下遮罩范围调节，设为 0 可完全关闭遮罩。
• 新增「启动时加载 3D」开关：关闭后只播放前段 2D 入场，之后可手动加载模型；修复首次读取设置时仍加载 3D 的问题。
• 修复本地图片路径识别与载入重试；支持关闭 3D 后显示自定义壁纸。
• 左下角新增 3D 开关：档案依次退场后释放三维资源，再次开启重新载入并升起。
• 新增超级性能模式，保留动态效果；补全自定义画质控制，关闭性能模式后恢复之前的画质。
• 新增四边独立界面边距，支持向内或向外调整；修正下边距，让底部两排一起移动，中部组件保持位置。
• 暗色模式新增「仅选中档案标签使用强调色」选项，并修正归齐状态下的标签表现。
• 新增 HUD 曲面、独立鼠标追踪、局部界面磨砂，以及覆盖整个画面的颗粒、色散与暗角；各项可独立调整。
• 阵列根据镜头和屏幕范围自动补位，裁剪屏幕外档案，改善宽屏边角露出阵列尽头的问题；加强暗色边缘雾气。
• 新增亮色／暗色配色及逐张变色过渡，覆盖工作台、档案详情与独立查看器。
• 提供原版、连续频谱、层叠流波三种音乐律动；静止呼吸可独立开关。修复壁纸自身音效触发音乐归齐的问题。
• 新增波纹接力小游戏，完善游戏与工作台的进出过渡。
• 新增桌面工作台：时间日期、今日事项、重要日程倒计时、系统媒体信息和专注计时；支持按需隐藏内容与关闭功能入口。
• 修复切歌时封面、歌曲文字和进度相互覆盖的问题，完善工作台入场、退场与操作衔接。
• 开场适配不同屏幕比例，移除底部字幕，并提供完整／简短入场选择。
• 完成 Wallpaper Engine 适配：本地资源打包、原生属性分组、音频响应、媒体信息、宿主帧率与暂停通知。
