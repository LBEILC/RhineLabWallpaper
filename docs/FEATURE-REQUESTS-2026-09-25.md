# 功能反馈与实现记录（2026-09-25）

本页单独保存八项反馈及最终实现。用户已授权实施，并确认菜单移动指左侧时钟／事项、右侧功能面板和底部导航的位置调整。以下功能已完成，验证见 [WORKBENCH-CONTROLS.md](../verification/WORKBENCH-CONTROLS.md)。

## 1. 壁纸内切换模式

页脚增加模式按钮，在工作台和档案展示之间切换。WE 的启动默认模式决定初始状态，页面按钮只影响当前运行，重载恢复默认；切换保留档案和工作台进度。

## 2. 按需打开完整工作台

页脚增加「完整工作台」按钮。开启时显示全部工作台元素与五项功能；关闭后恢复最新 WE 显示和功能配置，以及之前的页面模式。尚未手动切换页面模式时采用当前 WE 默认模式。运行中修改 WE 配置不会打断临时完整状态，事项与计时不重置；临时状态不跨重载保存。

WE 独立「页脚」分组包含四项默认开启的开关：显示页脚信息、显示页脚时间、显示模式切换按钮、显示完整工作台按钮。两个按钮相互独立，也不受页脚信息开关控制。3D 和重播继续可用。完整工作台不强制打开已隐藏的页脚信息；窄屏的新按钮放在同一独立行。

## 3. 调整工作台区域位置

原反馈：a feature for relocating workspace menus could be added。用户已确认调整区域位置。

WE「工作台 · 区域位置」为左侧时钟／事项、右侧功能面板、底部导航分别提供横向、纵向偏移，范围 −300～300 画面像素，默认 0，正值向右／向下。与全局边距及 HUD 曲面叠加，外移限制到视口边缘，不移动三维镜头。用户仍可主动让区域重叠，不自动重排。

## 4. 部分功能关闭后的序号

导航和右侧内容共用可用功能列表，连续编号为 01…N。当前功能关闭时选择首个仍可用项，全关时隐藏内容与导航，功能数据保留。

## 5. 独立页脚时间开关

关闭时间只隐藏时间及其分隔符，不影响姓名、SESSION 和按钮；关闭页脚信息整体时，时间也隐藏。

## 6. 专注完成提醒

专注倒数连续运行到零时播放一次短电子提示。WE「声音」内有独立的「专注结束提示音」开关，默认开启，同时遵循总音效开关与音量。休息结束、手动重置和切换阶段不提醒。暂停、隐藏或重载后才发现已结束，不补播迟到提醒；重新开启提示也不补响。真实 WE 播放链路已验证，听感可由用户试听后调整。

## 7. 更高音乐律动幅度

WE 滑杆与三种律动计算同步提高到 300%，默认保持 100%，原 0–200% 效果保持一致。已检查持续模拟频谱下的运动与画面。

## 8. 按钮点击声音

模式切换、完整工作台、3D、事项与计时操作播放短 UI 声，WE「声音」内通过独立的「按钮点击音效」开关控制，默认开启，并遵循总音效开关。导航保留已有选档声，玻璃动作声仍由总音效控制；已有音效的操作不重复叠加，禁用、隐藏及无效操作不发声，沿用音量与限频。

使用说明见 [WALLPAPER-ENGINE.md](WALLPAPER-ENGINE.md)。实现入口为 src/workbench-visibility.ts、src/workbench.ts、src/workbench-state.ts、src/workbench-position.ts、src/main.ts、src/audio.ts、src/archive-play-motion.ts 和 wallpaper/project.json。
